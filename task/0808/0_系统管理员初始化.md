请实现系统初始化管理员功能。

背景：
当前数据库已经完成初始化，已有表：
sys_user
sys_role
sys_user_role
sys_permission
sys_role_permission

目标：应用第一次启动时，自动创建系统超级管理员账号。

要求：
一、实现初始化类
新增：DataInitializer
位置请按照当前 Spring Boot 项目结构设计。

要求：
- 使用 CommandLineRunner 实现
- Spring Boot 启动完成后自动执行
- 使用事务保证数据一致性
- 不修改数据库表结构

二、初始化超级管理员角色
如果 sys_role 中不存在：role_code = SUPER_ADMIN
则创建：
role_name:超级管理员
role_code:SUPER_ADMIN

如果已存在，则直接使用已有角色。

三、初始化管理员账号
如果 sys_user 中不存在：
username = admin
则创建：
username:admin
password:admin123456

要求：
- 使用 BCryptPasswordEncoder 加密
- 数据库中禁止保存明文密码

如果 admin 用户已经存在，则跳过创建。

四、创建用户角色关系
检查：sys_user_role
